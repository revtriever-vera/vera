# Landing page

Site estático, sem build. `index.html` é o português, `en/index.html` o inglês, `style.css` e `img/` são compartilhados.

Para ver: abra `index.html` no navegador, ou rode `python3 -m http.server -d landing` na raiz do repositório.

As imagens em `img/` são capturas do protótipo (`prototipo/index.html`) com dados de exemplo. O domínio e a publicação ficam no card #26.
